# 学习路线

本仓库按「概念 → 最小可编译示例 → 自测」推进。

## 阶段一：语法与管线基础（01–08）✅

| 课次 | 主题 | 要点 |
|------|------|------|
| **01** | 管线与着色器骨架 | GLSL、`gl_Position`、varying、`precision` |
| **02** | 类型与向量运算 | `vec2`/`vec3`、swizzle、`mix`（含纯色与渐变） |
| **03** | uniform 与属性 | `layout(location=…)`、`requestAnimationFrame` |
| **04** | 纹理采样 | `sampler2D`、`texture()`、UV |
| **05** | 简单图案与 SDF | 圆/矩形距离场、`smoothstep` 抗锯齿 |
| **06** | 噪声与程序化动画 | hash、value noise、fBm、`uTime` 域扭曲 |
| **07** | 变换矩阵 | `mat3`、`uModel`、2D TRS、列主序 |
| **08** | 基础光照 | 法线、Lambert、Blinn-Phong、伪球面法线 |

> **阶段一已完结**（第 01–08 课）。

## 阶段二：图形小实验（09–10）✅

| 课次 | 主题 | 要点 |
|------|------|------|
| **09** | 进阶 SDF | `min`/`max` 布尔、smoothmin、多形状软融合 |
| **10** | 综合小实验 | SDF + 噪声域扭曲 + 简易光照 + 动画调色 |

说明：**纯色与渐变** 已在第 02–03 课通过 `mix` 与 uniform 动画覆盖，不再单独设课。

> **阶段二已完结**（第 09–10 课）。

## 阶段三：真实 3D 图形（11–15）✅

| 课次 | 主题 | 要点 |
|------|------|------|
| **11** | 三维坐标与 MVP | `mat4`、裁剪空间、透视除法、程序化立方体 |
| **12** | 透视投影与视锥体 | FOV、near/far、视锥平面、线框可视化 |
| **13** | 相机与深度 | `lookAt`、深度缓冲、Z-fighting |
| **14** | 三维网格光照 | 顶点法线、法线矩阵、方向光 + 点光 |
| **15** | 综合场景收官 | 地面 + 多物体 + 双光源，整合 MVP/深度/光照 |

共享工具：[`lessons/_shared/webgl2-math.js`](../lessons/_shared/webgl2-math.js)（`mat4`、网格生成）。

> **阶段三已完结**（第 11–15 课）。
