# 第 02 课自测题答案

> 建议先自己做题，再展开本页。

## 1. 表达式 `vec3(1, 2, 3) + 1.0` 能否通过编译？若不能，应如何改写？

**不能通过编译**。`vec3(1, 2, 3)` 的三个分量是 **int 字面量**，与 `float` 标量 `1.0` 相加时，GLSL 不会自动把 int 提升为 float。

应改为浮点字面量或显式转换，例如：

```glsl
vec3(1.0, 2.0, 3.0) + 1.0
// 或
vec3(float(1), float(2), float(3)) + 1.0
```

结果均为 `(2.0, 3.0, 4.0)`（标量 `1.0` 广播到三个分量）。

## 2. `vec4 c = vec4(1.0, 2.0, 3.0, 4.0);` 执行 `c.rg = c.ba;` 后，`c` 的四个分量分别是多少？

赋值前（rgba）：`r=1`，`g=2`，`b=3`，`a=4`。

`c.ba` 取右值 swizzle，得到 `vec2(b, a) = (3, 4)`。再赋给左值 `c.rg`：

- `r ← 3`，`g ← 4`
- `b`、`a` 未被写入，仍为 `3`、`4`

因此 **`c = (3, 4, 3, 4)`**（rgba 语义）。

注意：若写成 `c.rg = c.gr`，因读写同一向量且分量重叠，行为在规范中未定义；本题 `c.rg = c.ba` 读写分量无重叠，结果确定。

## 3. `mix(a, b, t)` 当 `t = 0.0`、`t = 1.0`、`t = 0.5` 时各得到什么？`smoothstep(0.0, 1.0, 0.5)` 约等于多少？

`mix(a, b, t)` 等价于 `a * (1.0 - t) + b * t`：

| `t` | 结果 |
|-----|------|
| `0.0` | 完全是 **`a`** |
| `1.0` | 完全是 **`b`** |
| `0.5` | **`a` 与 `b` 的算术平均**（各一半） |

`smoothstep(0.0, 1.0, 0.5)`：在 `e0=0`、`e1=1` 时，公式为 `3t² - 2t³`，代入 `t=0.5` 得 **`0.5`**。此时曲线在端点一阶导数为 0，中点仍为 0.5，但过渡比线性 `step` 更平滑。
