# 第 05 课自测题答案

> 建议先自己做题，再展开本页。

## 1. `float d = length(p) - radius` 中，`d < 0` 表示像素在圆的哪一侧？若改用 `step(0.0, d)` 硬切，边缘可能出现什么问题？

**`d < 0` 表示像素在圆的内部**（到圆周的有符号距离为负，越负越深）。

若用 `1.0 - step(0.0, d)` 做硬遮罩，边界处会在 **一个像素内** 从 0 突变到 1，没有过渡带。在斜率较大的边缘，屏幕像素网格会产生 **锯齿（aliasing）**——远看边缘呈阶梯状。`smoothstep(0.0, edgeWidth, d)` 在边界附近留出约 1～2 像素宽的渐变，视觉上更平滑。

## 2. 矩形 SDF 里 `vec2 q = abs(p) - halfSize` 这一步在几何上做了什么？为什么内部点的 `d` 会是负数？

**`abs(p)`** 把坐标翻到第一象限，利用矩形关于坐标轴的对称性，只需分析一个象限。

**`q = abs(p) - halfSize`** 相当于把矩形的「半边长框」从原点向外推：  
- 若 `abs(p)` 的分量 **小于** `halfSize`，对应轴上的 `q` 为 **负**，说明该轴方向仍在矩形 **内部**；  
- 若 **大于** `halfSize`，`q` 为正，说明已超出该边。

完整 SDF 公式中，`min(max(q.x, q.y), 0.0)` 在内部取负值，与外部的正距离相加后，**内部点的 `d` 为负**，表示「在形状里面」。

## 3. 两个形状的距离 `dA`、`dB` 若要画「同时属于两者」的交集区域，应对 `dA` 与 `dB` 用 `min` 还是 `max`？为什么？

应使用 **`max(dA, dB)`**。

交集要求像素 **同时** 在 A 内且在 B 内，即两者距离都应为负，且「更靠外」的那个形状决定你是否还在交集里——只有 **两个距离都足够负** 时，取较大（更接近 0 或为正）的那个仍 ≤ 0 才留在交集内。`max` 取「更限制人」的边界；`min` 对应 **并集**（在任一形状内即可）。
